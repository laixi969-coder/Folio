FOLIO / FIGURE STUDY

图片版式，换一套排法

参考归藏图文卡片（guizang-social-card-skill）里关于图片的处理规则，落到公众号长文能用的内联结构上。下面每一块都由 Folio 导出时的同一个渲染函数生成，不是另画的样稿。

  • 截图包壳：截图不再裸奔，纸色底 + 发丝线 + 内边距，边界清楚。
  • 图版标记：FIG. 编号放在图上方，文字永远不压照片（对应其「文字压图 + 主体避让」的降级做法）。
  • 图文并置：58/42 分栏，说明移到右侧，对应杂志 col-2 recipe。
  • 主体位置：裁切时按主体所在位置选 25 / 50 / 75，避免人脸被切断。
样稿仅用于比较，不修改任何文章或已保存的风格。编辑器右侧「图片设计」里可选这四种新排法。
