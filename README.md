# 简序 Folio

个人使用的公众号长文排版工具。手机和电脑通过浏览器访问同一份草稿。

## 启动

推荐直接双击本目录中的 **启动简序.command**。第一次需已有 Node.js 22.12 或更新版本，依赖已安装。

也可以在终端执行：

```sh
cd /Users/caiwenbin/Folio
npm start
```

电脑打开 http://localhost:4173 。使用完在启动窗口按 Control+C 退出。修改源代码后执行 `npm run build`，再重新启动；开发模式为 `npm run dev`。

## 手机使用

双击 **手机连接.command**，或执行 `npm run start:lan`。电脑和手机连接同一 Wi-Fi，在手机浏览器打开启动窗口显示的局域网地址，输入窗口中的访问码。

电脑必须开机、保持服务运行。两端访问同一个服务才共享草稿。局域网采用 HTTP，适用于可信任的个人网络；不提供公网云同步。电脑防火墙需要允许 Node 的局域网连接。启动前请退出另一个已运行的简序服务。

## 一键排版

粘贴文字或导入 Word、Markdown 文件后直接得到排版预览，选择「满意，去导出」即可。工具统一套用个人默认风格，并识别中文编号章节、数字子节和独立加粗标题。默认大标题32px、章节23px、二级19px、正文16px，导语与引语单独处理；副标题17px。工具自动整理连续图片，根据图片数量和位置选择满幅、留白、大小并排或主图加双图等版式，保留原比例。已有文章点击「一键排版」重新整理，可撤销。需要时再选「继续微调」，展开「手动微调排版」调整参数。

## 当前边界

1. 公众号剪贴板、图片上传、样式保留尚未用真实公众号账号验证。导出后请在微信真机预览，必要时补传图片。
2. 横滑在公众号兼容导出中转纵排，导出窗口明确提示；互动 HTML 用于浏览器。未接微信授权同步、SVG互动、自动发布。
3. 统一比例与主体位置以 CSS 样式写入导出；公众号是否保留裁切效果需在微信中预览验证。封面最终裁切在公众号后台完成。
4. Word复杂表格、批注、脚注与文本框会降级，请核对原稿。旧版 .doc 需先另存为 .docx。Markdown 支持标题、引用、列表、表格、代码块和图片。导入本地图片时，请在选择文件窗口中同时选择 Markdown 文件和所引用的图片；网络图片需允许浏览器读取。支持 PNG、JPEG、GIF 和 WebP，无法读取的图片会提示并中止导入。
5. 手机不依赖拖拽，使用移动按钮；支持按需调用已配置的文字和图片模型，日常排版与配图规则不依赖外部模型。
6. 手机操作系统的文件选取、剪贴板，以及不同微信客户端的最终视觉仍需实机验收。

## 数据与备份

`data/articles.json` 保存文章；`data/media/` 保存图片；`data/access-code` 是局域网访问码。不要把 data 上传到公开仓库。停止服务后复制整个 data 文件夹可完整备份。也可在文章导出窗口选择「备份可编辑原稿」，通过文章库底部「恢复备份」导入新文章。

本机目录数据不会发送给第三方。删除文章不会立即清理媒体文件，避免其他草稿使用的图片丢失。

## 杂志排版方向样稿

浏览器打开 http://localhost:4173/magazine/index.html 查看从开篇到结尾的完整样稿。源文件为 `public/magazine/index.html`，图片和来源保存在同目录。当前作为视觉提案，尚未纳入自动排版引擎；模型接入建议见 `public/magazine/DESIGN.md`。

## 已确认的默认风格与连接设置

当前默认已切换为「杂志 · 长文」，与确认的齐边样稿一致：手机左右30px、副标题15px、导语块、章节大号数字、引语及图片设计。旧稿保留原样，点击一键排版才应用新默认。

主页右上角「连接与发布」分别配置文字模型、图片模型、公众号。也可直接打开：

- http://localhost:4173/?settings=text
- http://localhost:4173/?settings=image
- http://localhost:4173/?settings=wechat

测试连接不发送文章，不生成图片；模型同步从服务商/models读取当前账号可见列表。小编工作台可主动调用模型生成标题摘要候选与图片；兼容协议和限制见下文。公众号支持自有账号凭据验证、素材上传与草稿创建和更新。完整流程和实现边界见CONNECTIONS.md。

`data/connections.json` 含本机连接密钥，权限600且不返回给浏览器；文件内容未加密。不要分享该文件。文章备份不含连接密钥。

## 五种副标题系列

风格面板和阅读预览提供「杂志章号、细线分隔、标签引导、居中题记、浅底标题」，支持一键替换或「随机换一套」。选择为文章级设置，开篇副标题与章节标题整篇统一；随机不重复当前系列。选择自动保存，一键排版保留；存为个人默认后新稿沿用。杂志样稿顶部也可直接切换，样稿选择只影响演示，不修改你的文章。


## 整篇系列

在编辑器「全文风格」或阅读预览选择「整篇系列」，一次同时替换文章配色与副标题/章节排法。提供青瓷章序、宫墙细线、黛蓝标签、秋香题记、藕荷浅笺、墨色留白六套组合。「随机整篇换一套」每次只选一套，并排除当前系列，全文不会逐段随机。

展开「单独调整配色与标题排法」可分别更换颜色和排法，也可随机只换配色。与预设不同的组合显示为「自定义组合」；点击任一整篇系列可恢复组合。字号、留白、正文、图片及图注保持原样。预览、自动保存、HTML 导出使用同一文章风格；重新一键排版仍保留所选系列（字号与间距按个人默认重新整理）。可在手动微调中「存为我的默认」。工作台品牌配色与文章配色独立。

完整交互样稿：启动后打开 `/magazine/index.html`。本项目的草稿、上传媒体、访问码及连接凭据位于 `data/`，不纳入 Git。


新增五套整篇系列：松烟侧线、赭石章序、黛石短线、苔绿边框、绛紫小点；全文统一切换配色与标题。新增图片排列：主图＋双图、左大右小、左小右大、居中留白、编号组图。图片顺序及图注保留；横向滑动兼容导出依旧转纵排。复制到公众号后应在微信真机预览检查实际排版。

## 自动图片排版

导入带图的 Word、Markdown 或对现有文章执行「一键排版」时，图片识别和布局推荐会自动执行，无需额外按钮。Mac 优先使用系统 Vision；其他支持 Node.js 和 ONNX Runtime 的运行环境使用跨平台图片分类模型。模型只在服务端处理图片，图片不会上传给模型提供方。识别不确定或不可用时按数量和比例排版，并在预览显示状态；已有图像内容及顺序保留，自动结果可撤销。

跨平台模型首次运行需要网络下载并缓存至数据目录的 `vision-model-cache`。部署时也可在构建／准备数据卷阶段执行 `npm run prepare:vision` 预热，或通过 `FOLIO_VISION_MODEL_PATH` 指定已准备好的模型目录（设置后不访问远程模型源）。如果无法下载或加载模型，文章仍可正常导入，但只有基础排版；请在目标部署环境验证模型文件、Node 与原生依赖的兼容性。此项目目前为需要持久存储和 Node 进程的 Express 服务，不能直接视为支持任意无状态或无磁盘的部署平台。

### 文章字体

编辑时在「全文风格」选择版式默认、黑体、宋体、楷体，或输入设备已安装的自定义字体名称；预览中的「调整样式」也可切换。可通过「手动微调排版」里的「存为我的默认」用于新文章。字体选择随文章保存，重新一键排版时保留。自定义字体不会随文章嵌入，实际显示取决于阅读设备和微信的字体支持，请在发布前使用手机预览。

### 局部调整字号

在编辑区选中一段文字（也可跨段选择），在工具栏的「选中文字字号」输入 10–72 px 并点击「应用字号」。如果要同时调整不相邻的完整段落，点击「选择多个内容块」，勾选文字内容块后输入「所选段落字号」并应用。图片和分隔线不会被改变。局部字号随文章保存并用于预览、复制和 HTML 导出，可以使用撤销恢复。

### 局部调整字体

文字与段落格式工具栏会停留在文章上方：拖选文字后可选择字体并点击「应用字体」；点「多选段落」后依次点击或勾选多个段落，再统一应用字号或字体。自定义字体输入设备已安装的字体名称。局部字体与字号可分别设置，并随文章保存和导出。设备或微信缺少指定字体时会使用替代字体。


### 阅读体检与发布准备

编辑器和预览顶部新增「阅读体检」：检查长段、连续密集文字、加粗比例、正文局部字号及二级标题前缺少一级标题。支持 120 / 180 / 260 字提示线、定位正文、忽略与恢复建议；只给阅读建议，不自动改写、不阻止导出。建议随原文变化重新检查，图注、代码和引用不套用正文规则。

「导出」窗口现在可填写独立发布标题、摘要、作者与封面。旧稿未设置独立发布标题时沿用文章标题；摘要留空时 Folio 不摘取正文，微信最终摘要需核对。缺少标题或封面仅阻止草稿同步，不影响正文复制与下载。摘要会随草稿创建或更新传给微信。

发布准备显示当前公众号下的历史同步版本、时间和本地修改状态；只是 Folio 保存的记录，不是远端草稿实时状态，也不代表正式发布。更换公众号后读取对应账号的记录。此次新增后端状态接口，已经运行的旧服务需重启后再使用。


## 小编工作台（完整编辑流程）

文章顶部点击「小编工具」，统一使用以下能力：

- **通读标记**：预览开启「边读边标记」，在具体内容块记录修改意见或记住阅读位置。备注可定位、处理和重新打开；原段删除后提示重新关联。备注不进入正文导出。
- **栏目与组件**：内置观点长文、人物故事、活动回顾、产品介绍；可保存多套自定义栏目，绑定开头与结尾组件。先预览后应用，可撤销。来源声明、作者介绍等组件可用 Markdown 编写或从选中内容建立。插入的组件是独立副本。
- **排版比较**：用同一篇真实文章比较克制阅读、杂志叙事、重点速读，提供完整正文滚动预览与整篇缩略图。只修改全文风格，保留原文、图片顺序及局部文字格式。
- **配图工作单**：记录位置、画面用途、描述、比例与替代方案；可复用本篇和素材库图片。素材库记录来源、授权备注、生成来源与使用文章；来源记录不是版权核验。外部图片模型只接收主动提交的画面描述，结果保存后仍需选择才插入。
- **阅读入口**：从原文建立候选、手动拟定，或主动向文字模型发送可查看的正文片段。整组比较标题、摘要、封面、读者、理由与原文依据；核对后才能采用。修改标题或摘要会清除核对状态，原文变化也会要求重新核对。
- **发布复盘**：手动记录账号、栏目、主题、发布链接和时间，保存当时标题与版式快照；按观察小时记录阅读、点赞、分享、收藏。仅比较同账号、栏目、主题和观察窗口的文章，可导出 CSV。未填数据保留为空，不冒充零值或因果结论。
- **发布过程记录**：导出窗口及复盘页分开记录正文复制、草稿同步、用户真机确认和手动发布确认；正文与版式改变会使真机确认失效。封面支持横向与方形参考预览及独立焦点保存，微信端仍需自行确认最终裁切。

栏目、组件和素材库保存在 `data/editorial-library.json`，有版本冲突保护，同服务的手机和电脑共用。完整备份仍可停止服务后复制整个 `data` 目录；单篇备份现也包括未采用候选的封面与尚未插入的生成图。库更改不追溯改变旧文章。

### 模型适配和验证边界

文字适配 `/chat/completions`，检查 JSON 格式、标题摘要长度与原文引用；图片支持百炼 Qwen-Image 原生同步接口，以及 `/images/generations` 的 PNG/JPEG/WebP base64 数据。仅百炼官方接口返回的受限 OSS 结果地址可由服务端下载，下载不携带 API Key。GPT Image 模型使用默认 base64，其他兼容模型请求 `response_format=b64_json`。仅支持这些协议的服务商可使用；模型列表可见不保证支持生成。

工作台生成改用持久后台任务，关闭页面不再中止已提交请求；失败需核对后手动重试，服务商可能仍产生费用。旧的直接生成接口和设置中的试运行仍支持取消请求。提示和生成来源随结果保留；生成画面不作为真实现场或统计证据。应用内不内置密钥。

所有本机工作流和模拟模型/微信接口均有测试；真实 GLM-5.3-Flash 文字和 Qwen-Image-2.0 图片生成已在 2026-11-07 跑通，见后文。2026-11-07 对已有公众号凭据进行了连接验证，微信返回 IP 白名单问题，没有上传内容或发布文章。需在公众号后台配置实际服务出口 IP 后才能进行真实草稿与微信真机验收。


### 书刊排版与国内模型

- 「整篇系列」新增燕麦书页、素白书刊、青瓷手记，字体、章号、导语、引文及留白同步进入公众号兼容 HTML。手动微调中的「存为我的默认」用于以后新建文章。
- 「连接与发布」可一键填入 DeepSeek、通义千问、智谱的官方地址和文字模型；填写相应 API Key 后，点「试运行文字生成」校验实际调用与 JSON 输出。模型列表不可用时仍可试运行。图片生成须另配绘图模型。
- 复制成功后记录对应内容版本；后续内容更改显示为之前版本。公众号 IP 白名单不会影响本地排版、复制和下载，但仍会阻止微信 API 同步。

## 自动成稿与人工交稿

编辑页点击 **自动成稿**（也可从小编工具进入），依次检查结构、推荐排版、审阅变化并下载交稿包：

1. 自动识别章节、开篇导语与有明确来源标识的图注，按句末停顿拆长段。对照修改前后逐项选择或全部采用，文字与图片顺序不变。
2. 按文章结构、列表密度及图片数量推荐书刊或速读风格；已确认的同名栏目风格优先。锁定内容块、已有局部字体字号及整理后改过的内容会受到保护。可记住栏目风格，或锁定整篇风格。
3. 采用时准备三组原文入口候选。文字模型为单独勾选项，会展示将发送的素材；长文按全文位置分布取样，包含文末，每段仍可能截取。模型结果需核对并采用，不自动改写正文。
4. **后台任务**保存文字、生成图片及本机素材整理的进度和结果；换页或刷新不终止服务器任务。结果先留在任务中心，收取后进入候选或配图工作单。正文变更后阻止采用旧模型结果，相同输入复用已有任务。服务退出或重启时不自动重放未知是否计费的任务，核对后手动重试。
5. 素材按内容哈希去重、检查真实尺寸、按比例与文件名分类。普通大图可生成独立轻量版本；截图/图表及动图保留原像素。原图、来源、备注及使用记录保留，轻量版需预览后主动插入。分类和尺寸提示不能替代目测清晰度或版权核对。
6. **下载完整交稿包**得到 ZIP：公众号兼容正文（图片内嵌）、发布信息、封面（已设置时）、待审清单、正文文本及 `.folio.json` 可编辑备份。可下载有待审事项的稿件，但缺失正文图片会阻止打包。自动流程没有正式发布操作。
7. **发布复盘 → 导入复盘 CSV**支持 BOM、带引号逗号/换行、字段映射、按 ID / 已存链接 / 唯一标题匹配，以及逐行手动指定文章。预览并核对账号、时间与固定观察窗口后导入；同篇多行需先选定一个窗口。已存发布快照不被覆盖，没有历史快照时必须确认当前稿对应发布版本。空单元格为未记录，未提供的指标列保留历史值；有并发修改时停止并提示此前已处理数量。
8. 重复整理跳过已确认且未变的内容块；阅读规则复用未变 HTML 的分析，导出图片检查复用本机会话内的不可变素材数据。最近一次整理前的正文/样式快照随稿保存，可在之后没有新的正文/风格修改时恢复；其他操作仍可使用编辑器撤销。

任务文件为数据目录下的 `editorial-jobs.json`（权限 0600，包含已提交素材和结果、不包含模型密钥）。服务需要持续运行才能执行后台任务。素材分析与压缩使用本机 Sharp，图片不因整理而上传外部服务。

### 精选章节样式

章节标题与整篇系列按视觉差异精选，不固定数量。目前推荐燕麦书页、居左色点、色点章序（居中）、宋体留白框、松烟侧线；藕荷浅笺的浅底块样式退出推荐与随机选择。配色仍可独立调整。其他旧样式保留渲染和备份兼容，不自动改写旧稿。


### 章题留白与复制兼容

原「宋体斜线」改为「宋体留白框」，小章号、细边框和框内留白与其他款形成差异。五款推荐章题共用编辑、预览和复制/导出的内联 HTML，不需要额外样式表，不使用布局表格、Flex/Grid 或绝对定位。居左/居中色点在长标题时适度收小字号；移除固定窄标题栏与超大空白，金额等短数字单位尽量不断开。
